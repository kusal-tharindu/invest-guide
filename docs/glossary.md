# Glossary

Terms in the order I meet them.

**ETF (Exchange-Traded Fund)**
:   A fund that holds many investments and trades on a stock exchange like a share.

**Index**
:   A list of investments with a rulebook and a number that measures how the group performs. You cannot buy it directly.

**Index fund**
:   A fund that follows an index, usually bought directly from the fund company.

**TER (Total Expense Ratio)**
:   The yearly fee a fund charges, shown as a percentage of the amount invested.

**Tracking difference**
:   The gap between a fund's return and its index's return.

**Domicile**
:   The country where a fund is registered.
